## О проекте

**Markdown Viewer** — это современное веб-приложение для просмотра Markdown-ответов, полученных от нейросети и сохранённых в базе данных.

Проект предназначен для удобного отображения структурированного текста, кода, формул и технических ответов.  
Для доступа к просмотру реализована аутентификация пользователя через Telegram, которая подтверждает право на просмотр ответа.

---

## Основной функционал

- Аутентификация пользователя через Telegram
- Проверка доступа к просмотру ответа от нейросети
- Удобный рендеринг Markdown
- Подсветка и копирование кода
- Поддержка LaTeX-формул
- Структурированный и читаемый интерфейс
- Адаптивная верстка

## Установка

Стандартная установка Vue-проекта через `npm install`.

### Шаги

```bash
npm install
```

---

## Запуск

```bash
npm run dev
```


После запуска приложение будет доступно по адресу, указанному в терминале.

---

## Особенности

- Современный интерфейс для чтения Markdown
- Поддержка технических ответов с кодом и формулами
- Telegram-based access control
- Удобный UX для просмотра длинных текстов
- Подходит для интеграции с AI-сервисами и базой данных
